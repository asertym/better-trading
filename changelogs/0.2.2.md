# 0.2.2

## Added

- Dock the panel on the left or the right; the choice is remembered. _(thanks @BigBadBodyPillow)_
- Choice to pin the item trends panel so it stays open across searches.
- Toggle last observed prices in bookmarks from the Settings.
- Can drag & drop between folders.

## Changed

- Tab titles now reflect the exact search, including item name, category, rarity, and selected filters. _(thanks @slothofexile)_
- History records the exact submitted search and shows its item name when available. _(thanks @slothofexile)_
- Searches are recorded only when submitted: the Search button, Enter in a search input, or back/forward navigation.
- Bookmarks drag and drop now previews cross-folder moves live and follows the cursor with a clean overlay.
- Folder and trade action menus are proper dropdowns with proper closing.
- Delete folder is available on every folder, not just archived ones.
- "Update trade location" is now labeled "Update to current search".
- Backup tools moved into the About panel.
- The update notice links straight to the changelog, also reachable from About.
- Lots of other smaller optimizations and improvements.
- Swapped the icon set to Phosphor.
- Interface cleanup
- More to follow.

## Fixed

- History entries without a title now show "Search" instead of the raw link. _(thanks @slothofexile)_
